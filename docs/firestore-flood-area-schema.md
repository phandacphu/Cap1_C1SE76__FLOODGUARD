# Firestore Flood Area Schema

## Collection

```text
flood_areas/{areaId}
```

The collection name follows the Firestore data model created in CCF-14.

## Fields

| Field | Type | Required | Description |
|---|---|---:|---|
| `name` | string | Yes | Human-readable flood area name |
| `description` | string or null | No | Additional area information |
| `geometry.type` | string | Yes | Currently fixed to `polygon` |
| `geometry.points` | array of maps | Yes | Polygon points containing `latitude` and `longitude` |
| `severity` | string | Yes | `low`, `medium`, `high`, or `critical` |
| `status` | string | Yes | `active` or `inactive` |
| `source` | string | Yes | Source or label for the sample/manual data |
| `createdAt` | Firestore Timestamp | Yes | Server creation time |
| `updatedAt` | Firestore Timestamp | Yes | Server update time |

## Geometry Point

Each item in `geometry.points` uses this structure:

```json
{
  "latitude": 16.0544,
  "longitude": 108.2022
}
```

A polygon must contain at least three valid points.

Validation ranges:

```text
latitude:  -90 to 90
longitude: -180 to 180
```

## Example Document

```json
{
  "name": "Sample Flood Area 01",
  "description": "Simulated flood area for API and map testing",
  "geometry": {
    "type": "polygon",
    "points": [
      {
        "latitude": 16.0544,
        "longitude": 108.2022
      },
      {
        "latitude": 16.056,
        "longitude": 108.206
      },
      {
        "latitude": 16.052,
        "longitude": 108.208
      }
    ]
  },
  "severity": "high",
  "status": "active",
  "source": "FLOODGUARD sample data"
}
```

`createdAt` and `updatedAt` are generated by the backend with Firestore server timestamps.

## Relationship

One flood area may be referenced by multiple documents in the `flood_alerts` collection.

The alert document and active-time fields will be defined in CCF-45.

## Prototype Data Notice

Flood area records used for development and demonstration are sample or simulated data. They must not be presented as official real-time flood information.
