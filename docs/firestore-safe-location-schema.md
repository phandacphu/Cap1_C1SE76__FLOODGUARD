&#x09;# Firestore Safe Location Schema



\## Source and Scope



This schema supports CCF-66 and is based on:



\- CCF-14 Firestore Data Model

\- CCF-66 task description

\- FLOODGUARD Proposal



CCF-14 defines the `safe\_locations` and `safe\_location\_services`

collections and their relationship, but does not define every field name.



The detailed fields below are the agreed MVP implementation for the

FLOODGUARD prototype.



\## Safe Locations Collection



```text

safe\_locations/{safeLocationId}

```



\### Fields



| Field | Type | Required | Description |

|---|---|---:|---|

| `name` | string | Yes | Human-readable safe location name |

| `address` | string | Yes | Full address of the location |

| `location.latitude` | number | Yes | Latitude from -90 to 90 |

| `location.longitude` | number | Yes | Longitude from -180 to 180 |

| `type` | string | Yes | Type of safe location |

| `capacity` | number | Yes | Maximum supported number of people |

| `capacityNote` | string or null | No | Additional capacity information |

| `description` | string or null | No | Additional location description |

| `contactPhone` | string or null | No | Contact phone number |

| `status` | string | Yes | `active` or `inactive` |

| `createdAt` | Firestore Timestamp | Yes | Server creation time |

| `updatedAt` | Firestore Timestamp | Yes | Server update time |



\## Allowed Safe Location Types



```text

shelter

school

hospital

community\_center

other

```



\## Location Validation



```text

latitude:  -90 to 90

longitude: -180 to 180

```



\## Capacity Validation



```text

capacity must be a non-negative integer

```



\## Safe Location Services Collection



```text

safe\_location\_services/{serviceId}

```



\### Fields



| Field | Type | Required | Description |

|---|---|---:|---|

| `safeLocationId` | string | Yes | Referenced document ID from `safe\_locations` |

| `name` | string | Yes | Service name |

| `description` | string or null | No | Service description |

| `isAvailable` | boolean | Yes | Whether the service is currently available |

| `createdAt` | Firestore Timestamp | Yes | Server creation time |

| `updatedAt` | Firestore Timestamp | Yes | Server update time |



\## Relationship



One safe location may provide multiple services.



```text

safe\_locations/{safeLocationId}

&#x20;       |

&#x20;       +---- safe\_location\_services/{serviceId}

```



Each service stores the related safe location ID in:



```text

safeLocationId

```



The backend must verify that the referenced safe location exists before

saving a service.

\## Example Service Documents



```json

{

&#x20; "safeLocationId": "ccf66-sample-safe-location-01",

&#x20; "name": "drinking\_water",

&#x20; "description": "Sample drinking water support",

&#x20; "isAvailable": true

}

```



```json

{

&#x20; "safeLocationId": "ccf66-sample-safe-location-01",

&#x20; "name": "first\_aid",

&#x20; "description": "Sample first-aid support",

&#x20; "isAvailable": true

```



`createdAt` and `updatedAt` are generated by the backend with Firestore

server timestamps.



\## Prototype Data Notice



Safe locations and available services used for development and

demonstration are sample or simulated data.



They must not be presented as verified emergency shelters without

confirmation from an authorized data source.
