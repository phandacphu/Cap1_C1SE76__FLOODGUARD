\# Rescue Assignment Data



\## Jira Task



CCF-94 - RESCUE-DB-01 Rescue Assignment Data Firestore



\## Scope



This task creates the Firestore data layer for assigning one Rescue Staff

to one SOS request.



No HTTP endpoint or mobile UI is included in this task.

The service is intended for use by CCF-98, CCF-99, and CCF-100.
