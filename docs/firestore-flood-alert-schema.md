\# Firestore Flood Alert Schema



\## Collection



```text

flood\_alerts/{alertId}

```



The collection name follows the Firestore data model created in CCF-14.



\## Fields



| Field | Type | Required | Description |

|---|---|---:|---|

| `title` | string | Yes | Short warning title |

| `content` | string | Yes | Warning details and safety information |

| `severity` | string | Yes | `low`, `medium`, `high`, or `critical` |

| `status` | string | Yes | `active` or `inactive` |

| `areaId` | string | Yes | Referenced document ID from `flood\_areas` |

| `startAt` | Firestore Timestamp | Yes | Warning effective start time |

| `endAt` | Firestore Timestamp | Yes | Warning effective end time |

| `createdAt` | Firestore Timestamp | Yes | Server creation time |

| `updatedAt` | Firestore Timestamp | Yes | Server update time |



\## Time Rules



```text

startAt must be earlier than endAt

```



A warning is considered currently active when all conditions are true:



```text

status = active

startAt <= current time

endAt >= current time

```



The backend will apply these conditions when implementing CCF-47.



\## Area Relationship



`areaId` references:



```text

flood\_areas/{areaId}

```



The backend must verify that the referenced flood area exists before saving a flood alert.



One flood area may have multiple flood alerts over time.



\## Example Document



```json

{

&#x20; "title": "Sample High Flood Warning",

&#x20; "content": "Simulated warning for API and map testing",

&#x20; "severity": "high",

&#x20; "status": "active",

&#x20; "areaId": "ccf44-sample-flood-area-01",

&#x20; "startAt": "Firestore Timestamp",

&#x20; "endAt": "Firestore Timestamp"

}

```



`createdAt` and `updatedAt` are generated by the backend with Firestore server timestamps.



\## Prototype Data Notice



Flood alerts used for development and demonstration are sample or simulated data. They must not be presented as official real-time flood warnings.
